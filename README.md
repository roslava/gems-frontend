# Литотека — тестовая витрина (React)

Простой рабочий фронтенд для проверки наполнения базы Samotsvety API.
Две страницы: каталог образцов и карточка минерала.

## Запуск

```bash
npm install
cp .env.example .env   # при необходимости поменяйте VITE_API_BASE_URL
npm run dev
```

Откроется на http://localhost:5173. По умолчанию API ожидается на
`http://localhost:8080` — поменяйте `VITE_API_BASE_URL` в `.env`, если
бэкенд крутится в другом месте.

**CORS**: если API отдаёт ошибку CORS в консоли браузера, разрешите
`http://localhost:5173` на бэкенде.

## Что внутри

- `src/api.js` — обёртка над `/api/v1/minerals`, `/minerals/{slug}`, `/search`.
- `src/pages/CatalogPage.jsx` — список карточек, поиск, фильтр по редкости,
  фильтр "только российские месторождения", пагинация.
- `src/pages/MineralPage.jsx` — детальная карточка: научные данные,
  цвет, lore, месторождения, галерея, безопасность, похожие минералы;
  переключатель "С эзотерикой" дергает `?view=esoteric` и показывает
  блок `esoteric`, если он есть в данных.
- `src/styles.css` — стили на основе палитры и токенов вашего UI-кита
  (Кварц / Базальт / Малахит, карточки со срезом-огранкой).

## Что сознательно упрощено (это v1 для теста)

- Нет переключателя языка (всегда `lang=ru`) — добавить легко, `api.js`
  уже поддерживает параметр `lang`.
- Нет отдельного экрана `/filters` со списком доступных значений —
  фильтры на каталоге захардкожены (редкость, российские месторождения).
- Нет обработки авторизации — используются только публичные GET-эндпоинты.
- Нет кэширования запросов — при желании можно добавить React Query.
