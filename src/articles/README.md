# Архив локального черновика

Этот каталог содержит сохранённую экспериментальную верстку статьи
«Почему одни камни прозрачные, а другие нет?». Он не подключён к маршрутам
и не используется для публикации.

Список, поиск, заголовки, обложки и содержание опубликованных статей
загружаются из API: /api/v1/posts, /api/v1/search/posts и /api/v1/posts/:slug.
Страница поддерживает content_blocks и Markdown из i18n.content.
Для публикации черновика его содержание необходимо добавить в API.
